# Session Handoff: C-21545 — var paths with an array index

**Date:** 2026-10-13
**Branch:** `geraldosilva/c-21545-bracket-index-paths`, off `origin/main` at `7498e1dd`.
**Pairs with:** trycourier/frontend#5540 (vendors this build as `0.10.0-vendor.516a8d834a4b`).

## Root cause

`{{var "tokens.expo[0].status"}}` passes its path to the send's variable handler, which reads it as JSONPath and prints the value. `varLiteralPath` handed the same string to `isValidVariableName`, which applies Handlebars' ID grammar, where `expo[0]` is not a legal segment. The path was judged malformed, so it never reached `useVariables`; Studio could not give it a preview value and the preview printed the raw `{tokens.expo[0].status}`.

## Fix

`varLiteralPath` spells a JSONPath index as `.0` (`expo[0]` → `expo.0`, `grid[0][1]` → `grid.0.1`; Handlebars' own `.[0]` is left alone). Both grammars accept it, and a host value stored under it nests as `tokens → expo → 0`, which is what the preview's `var` helper walks. The chip check, the variable list and the rejected-variables check all go through `varLiteralPath`.
