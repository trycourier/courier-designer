## Changes (`packages/react-designer`)

- `MSTeams.tsx` appends `jsonnet` to the sidebar; `MSTeams/SideBar` renders `JsonnetBlock`; `MSTeamsSideBarItemDetails` renders `JsonnetForm`.
- `templates.ts`: `msteamsJsonnetTemplates` (Text With Button, Text With Image, Facts (Using Loops)). `JsonnetForm` shows them when `channelAtom === "msteams"`; `usePragmaticDnd` (sidebar drop) and `useBlockConfig().insertBlock` insert the first as the Teams default.
- Tests: sidebar expectations include `jsonnet`; Teams drop default + starter shape tests. Changeset `msteams-jsonnet-block.md` (minor).
